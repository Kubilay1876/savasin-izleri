YBS215 Web Tasarımına Giriş — HTML + CSS dönem projesi

NASIL AÇILIR?
1. Klasördeki index.html dosyasına çift tıklayın.
2. Site tarayıcıda açılır. JavaScript, framework veya sunucu gerektirmez.

SAYFALAR
index.html        Ana sayfa: giriş, kısa bilgiler, sergi salonları
cepheler.html     Altı muharebe kartı (Britanya, Midway, El Alamein,
                  Stalingrad, Normandiya, Berlin)
kronoloji.html    1939–1945 zaman çizelgesi (17 olay, yıl menüsü)
insani-yuz.html   Siviller, Holokost, göç, cephe gerisi ve savaş
                  yıllarında Türkiye
kaynaklar.html    Arşiv bağlantıları ve görsel lisansları

MUHAREBE DETAY SAYFALARI (hepsi aynı şablonu kullanır)
britanya.html, midway.html, el-alamein.html,
stalingrad.html, normandiya.html, berlin.html
Her birinde: künye (tarih, yer, taraflar, komutanlar, sonuç) ve
Arka plan → Muharebe → Sonuç ve önemi bölümleri.

GITHUB PAGES
Repo'nun kök dizininde index.html olmalı. Settings → Pages →
"Deploy from a branch" → main / (root). Tüm yollar göreli olduğu için
site https://kullaniciadi.github.io/repo-adi/ altında sorunsuz çalışır.
Dosya adları küçük harf ve Türkçe karaktersizdir (GitHub Pages büyük/küçük
harfe duyarlıdır).
